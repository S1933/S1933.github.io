A propos

Développeur full-stack depuis 2011, je construis des applications web robustes avec Drupal, Symfony et PHP. Depuis 2021 chez OVHcloud, je conçois et maintiens des briques logicielles critiques à l'échelle du cloud européen.

Passionné par l'intersection entre développement et intelligence artificielle, je crée des outils qui augmentent le quotidien des développeurs — de la revue de code assistée par consensus multi-modèle (Quorum) à l'automatisation des workflows avec les sub-agents Claude Code.

« Markdown Engineer » n'est pas qu'un titre : c'est une philosophie. Écrire du code comme on écrit de la documentation — lisible, intentionnel, maintenable. Le markdown comme format universel, le terminal comme plan de travail.
